01 / THE BUILD

What it does

Four joints give this desktop arm a reachable set of simple pick-and-place poses. The controller interpolates between saved positions so the movement is smooth enough to inspect and repeat.

A USB-powered controller could not safely supply several servos starting at once. A separate servo rail, shared signal ground and a slower start-up sequence stopped resets and reduced abrupt motion.

04 / FIRMWARE

A slice of the code

This helper moves one joint gradually between safe limits. Add your own calibration, mechanical limits and emergency stop before running a powered arm.

arm_control.ino
#include <Servo.h>

Servo shoulder;
int currentAngle = 90;

void moveJoint(Servo &joint, int target) {
  target = constrain(target, 15, 165);
  const int direction = target > currentAngle ? 1 : -1;
  while (currentAngle != target) {
    currentAngle += direction;
    joint.write(currentAngle);
    delay(14);
  }
}

void setup() {
  shoulder.attach(6);
  shoulder.write(currentAngle);
}

void loop() {
  moveJoint(shoulder, 72);
  delay(350);
  moveJoint(shoulder, 112);
  delay(350);
}

05 / LESSONS FROM THE BENCH

What I learned

Servo angles are only a convenient command, not a measurement of the arm’s true position. Mechanical backlash, link flex and joint limits need to be measured before trusting a path.

Add end-stop switches, mark the working envelope, and use a small inverse-kinematics solver to specify the gripper position in Cartesian coordinates.
