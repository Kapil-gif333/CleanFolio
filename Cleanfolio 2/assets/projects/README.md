# Project photos

Add up to three photos per project here. Use the project page slug and a two-digit position:

```text
obstacle-avoiding-rover-01.webp
obstacle-avoiding-rover-02.webp
obstacle-avoiding-rover-03.webp
quiet-growing-plant-monitor-01.webp
four-axis-desktop-arm-01.webp
```

WebP is preferred; `.jpg`, `.jpeg`, and `.png` also work. After adding images, run `npm run photos`. Cleanfolio writes the images into the real HTML project galleries and matching home-page thumbnails. Give each picture a clear view of the finished build, wiring, or a useful detail. Then edit each image's `alt` text in its project page so it accurately describes the picture.
