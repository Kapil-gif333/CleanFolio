# Contributing to Cleanfolio

Thanks for helping make this a clearer, more useful home for work in progress.

## Good first contributions

- Improve keyboard access, contrast, small-screen behavior, or reduced-motion handling.
- Fix a project generator edge case or improve its placeholder text.
- Add a well-documented example project with a legible diagram, pin notes, parts list, and tested code excerpt.
- Improve setup steps without adding required runtime dependencies.

## Before opening a pull request

1. Keep the published site static and dependency-free.
2. For project pages, include a unique title, description, canonical URL, Open Graph values, and `CreativeWork` JSON-LD.
3. Keep diagrams inline, keyboard accessible, and understandable without hover.
4. Use descriptive labels and preserve visible keyboard focus and reduced-motion support.
5. Run `npm run sitemap` after adding or renaming project pages.
6. Preview the home page and changed project pages at desktop and mobile widths.

Please do not add tracking scripts without a clear opt-in and a matching privacy explanation. Open an issue first for large visual or structural changes so we can agree on the direction.
